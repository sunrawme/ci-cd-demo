## Purpose

Python is a high-level, general-purpose programming language designed with an emphasis on code readability and simplicity.

This document provides an introduction to Python, covering its history, key features, and common use cases. It is intended to provide a basic understanding of why Python has become one of the most widely used programming languages.

## Pre-requisites

The following basic knowledge is recommended before learning Python:

- Basic understanding of computers and operating systems.
- Basic understanding of programming concepts.
- Familiarity with using a command-line terminal is helpful but not mandatory.

## 1. History of Python

Python was conceived in the late 1980s by Guido van Rossum at Centrum Wiskunde & Informatica (CWI) in the Netherlands, and its implementation began in December 1989.

Python was created as a successor to the ABC programming language. The goal was to address some of ABC's limitations while maintaining readability and simplicity.

### Key Milestones in Python's History

- **1991 — Python 0.9.0:** Python was released publicly. It already included classes, exception handling, functions, and core data types such as lists and dictionaries.

- **1994 — Python 1.0:** Python 1.0 was released and introduced functional programming tools such as `lambda`, `map`, `filter`, and `reduce`.

- **2000 — Python 2.0:** Python 2.0 introduced list comprehensions and a cycle-detecting garbage collector. It also represented a move toward community-driven development.

- **2008 — Python 3.0:** Python 3.0 was released as a major backward-incompatible revision. It cleaned up the language design and improved Unicode support.

- **2020 — Python 2 End of Life:** Python 2 officially reached end of life. The Python ecosystem subsequently transitioned to Python 3.

- **Present:** Python continues to be actively developed, with regular releases and a large ecosystem maintained by the Python community and the Python Software Foundation.
